Paste-proof format: looks the same in every Outlook paste mode, including the default Merge formatting. Your name, designation, contact details, logo, tagline and capsules are drawn as one sharp image, and your links and the CTA are image buttons. All links still work, and the alt text carries your full details. The trade-off: text in the image can't be selected or copied. Use the Email and Call buttons for tap-to-contact.

        
Before you paste, set Outlook to keep formatting. Since mid-2024, Outlook's default paste mode is Merge formatting. It strips font sizes, colors and link styles, so your name ends up the same size as your designation.

New Outlook / Outlook on the web: Settings › Mail › Compose and reply › Cut, copy and paste › Pasting from other apps → Keep source formatting.

Classic Outlook (Windows): File › Options › Mail › Editor Options › Advanced › Cut, copy, and paste › Pasting from other programs → Keep Source Formatting.

Or, straight after pasting, open the paste options button (the small ••• or clipboard icon) and choose Keep source formatting.

        
Copy for Outlook copies the finished signature with its images included. The Outlook dark preview simulates Outlook for Windows' color inversion. For Gmail or hosted setups, use Code with hosted image URLs.
